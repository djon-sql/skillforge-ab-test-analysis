# Агрегований експорт view

`skillforge_daily.csv` містить 40 рядків на рівні дата × група за 01–20.08.2025. `conver_rate` — частка позитивних статусів серед відомих за день, у відсотках.

Користувацький експорт `v_user_conversion` наразі не включений до публічної версії. Його структура й логіка визначені в SQL та ноутбуку.
