# Tableau

[Відкрити інтерактивний дашборд](https://public.tableau.com/app/profile/djon.fa/viz/SkillForce/01AB-).

Два дашборди: «Результати A/B-тесту» та «Аналіз сегментів». Перший показує головні KPI, статистичне підтвердження й динаміку; другий — розподіл і конверсію за країнами та пристроями.

Зображення головного дашборду збережено в assets/. Назва публікації у Tableau Public — SkillForce; назва навчального проєкту — SkillForge.
